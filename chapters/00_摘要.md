# 中 文 摘 要

高校规章制度、办事指南与课程资料常以多种格式分散存放,师生查找信息不够方便。针对这一问题,本设计实现了一个基于检索增强生成的智能校园知识库系统。管理员上传文档后,系统完成解析、切块和向量化;用户以自然语言提问,系统融合向量检索与关键词检索结果,由大语言模型依据检索证据生成回答。回答带有来源引用,用户可以预览原文核对出处;检索不到相关证据时系统拒绝作答。系统包含管理端和聊天端,能够完成文档入库、匿名问答和来源查看等功能,为校园信息查询提供便利。

关键词:检索增强生成；知识库问答；混合检索；校园信息化

# Abstract

Campus rules, service guides and course materials are stored in a variety of formats and scattered across different platforms, so teachers and students often need much time to find the information they need. This graduation project designs and implements an intelligent campus knowledge base system based on retrieval-augmented generation. Administrators upload documents in formats such as PDF, Word, Excel, PowerPoint and images. The system parses them, splits them into chunks according to the knowledge base template, and writes the chunk vectors into a vector database. When a user asks a question in natural language, the system fuses the results of vector retrieval and keyword retrieval, filters the candidates, and lets a large language model generate an answer from the retrieved evidence. The answer is pushed to the front end segment by segment through server-sent events, and it carries citation numbers so that readers can preview the original document and check the source. When no relevant evidence is found, the system refuses to answer. The administrative side and the chat side are complete in function, and the whole system can be run and demonstrated. It gives teachers and students a usable way to obtain campus information.

Keywords: Retrieval-Augmented Generation; knowledge base question answering; hybrid retrieval; vector retrieval; campus informatization
