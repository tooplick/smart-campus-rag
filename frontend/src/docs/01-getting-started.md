# 快速开始

Smart Campus RAG 是面向校园场景的知识库问答系统:管理员上传文档,用户用自然语言提问,系统给出带来源引用的回答。

## 用户:提问

1. 打开顶部导航的 **Chat**(或首页「开始提问」)。
2. 在输入框输入问题,回车发送;`Shift + Enter` 换行。
3. 回答以 SSE 流式输出,底部「参考来源」卡片展示命中的原文切片。
4. 点击来源卡片可预览文档原文;左侧栏可新建、切换、重命名或删除会话。

若回答提示「知识库尚未就绪」或连接错误,说明后台模型服务未启动,请联系管理员。

## 管理员:维护知识库

首次登录使用初始账号,登录后会被强制要求修改密码。

1. **知识库**:在「知识库」页新建知识库,选择切块模板。
2. **上传文档**:在「文档」页上传文件,系统自动排队解析、切块与向量化,进度实时可见。
3. **配置模型**:在「设置」页配置对话 LLM、Embedding、Vision 与重排模型,支持多套配置切换与连通性测试。
4. **调优检索**:同在「设置」页调整 RAG 参数,保存即热生效。
5. **检查效果**:在「问答日志」页回看每次问答的延迟、检索详情与引用来源。

## 切块模板怎么选

| 模板 | 适用场景 |
|---|---|
| general | 通用文档,句级流式切块带重叠 |
| section | 章节结构清晰的手册、规范 |
| qa | 本身就是问答形式的资料 |
| one | 短文档,整篇作为单切片 |
