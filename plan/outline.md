# 论文详细大纲

> 依据学校格式范本(6 章 + 致谢 + 参考文献)与用户确认的结构。

## 第1章 绪论

- 1.1 研究背景与意义 — 校园资料分散、格式多样、检索效率低;自然语言问答 + 出处引用的价值
- 1.2 国内外研究现状 — RAG 技术演进、知识库问答系统现状、校园场景应用
- 1.3 研究内容与目标 — 三大目标:自然语言问答带出处、全流程跑通、多格式文档入库
- 1.4 论文组织结构 — 各章安排说明

## 第2章 相关技术与理论

- 2.1 大语言模型与检索增强生成(RAG) — RAG 原理、检索增强 vs 微调
- 2.2 向量数据库与嵌入模型 — Qdrant、bge-m3、1024 维 COSINE 相似度
- 2.3 混合检索与重排技术 — 向量检索 + 关键词检索(Jieba/Bigram)、加权融合、重排
- 2.4 后端技术 — FastAPI、SQLAlchemy(async)、Pydantic v2
- 2.5 前端技术 — Vue 3、TypeScript、Vite、Pinia、Tailwind CSS
- 2.6 本章小结

## 第3章 系统需求分析

- 3.1 系统可行性分析 — 技术/操作/经济可行性
- 3.2 功能性需求 — 管理端(登录、知识库管理、文档管理、模型配置、问答日志)、聊天端(匿名会话问答、来源引用)
- 3.3 非功能性需求 — 性能、安全性、易用性、可维护性
- 3.4 用例分析 — 核心用例描述(管理员、普通用户)
- 3.5 本章小结

## 第4章 系统设计

- 4.1 总体架构设计 — 分层:API Route → Service → RAG Pipeline → 外部存储/模型
- 4.2 功能模块设计 — 各模块职责与接口
- 4.3 数据库设计 — PostgreSQL 主要表结构(知识库、文档、切片、会话、问答记录)
- 4.4 RAG 检索流程设计 — 混合检索 → 融合 → 阈值 → 重排 → 邻块扩展 → 生成
- 4.5 文档入库流程设计 — 解析 → 切块 → 增强 → 嵌入 → Qdrant upsert;Worker 机制
- 4.6 本章小结

## 第5章 系统实现

- 5.1 开发环境与部署 — Windows/Docker/uv/npm、端口
- 5.2 管理端实现 — 登录改密、知识库 CRUD、文档上传与进度、模型配置热切换
- 5.3 文档处理与入库实现 — 解析器分派、切块模板、Worker 阶段进度
- 5.4 RAG 问答链路实现 — SSE 流式对话、混合检索、引用生成
- 5.5 前端界面实现 — 统一壳层、聊天界面、来源预览
- 5.6 关键问题与解决 — 如切片不可变、配置热更新、错误归一化
- 5.7 本章小结

## 第6章 系统测试

- 6.1 测试环境 — 硬件/软件/依赖服务
- 6.2 功能测试 — 核心功能测试用例表(登录、上传、问答、引用、配置切换)
- 6.3 演示效果 — 端到端演示流程与界面效果(截图待补)
- 6.4 测试结果分析 — 通过情况;"测试与实现效果"对比数据待定
- 6.5 本章小结

- 7.1 工作总结 — 对照研究目标逐条回顾
- 7.2 不足与展望 — 对比实验数据待补、多用户权限、检索质量量化评估
