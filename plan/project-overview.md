## 研究信息

### 研究背景
校园资料分散在各类文档中,师生查找困难。

### 研究目的
让师生用自然语言问答直接拿到带出处的答案;系统能跑通全流程。

### 研究方法(技术方案)
- 后端 FastAPI + SQLAlchemy(async) + Pydantic v2;前端 Vue 3 + TypeScript + Vite + Tailwind
- 存储:PostgreSQL(业务数据)+ Qdrant(向量,campus_rag_chunks_v1,1024 维 COSINE)
- 入库:多格式解析(PDF/DOCX/TXT/MD/CSV/XLSX/PPTX/HTML/图片)→ 按知识库模板切块 → 可选 LLM 入库增强 → bge-m3 嵌入
- 查询:向量 + 关键词混合检索 → 阈值过滤 → 可选重排 → 邻块扩展 → LLM 生成,回答带来源引用
- 鉴权:管理端 JWT(单管理员);聊天端 X-Client-ID 匿名会话

### 实验策略
以项目演示为主;"测试与实现效果"对比数据章节**待定**(后续再定)。
